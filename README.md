# Dev Trail

เว็บทบทวนความรู้สำหรับนักพัฒนา 17 หัวข้อ อ่านให้เข้าใจ ลองตอบคำถาม ทำแบบฝึกหัด และทำบททดสอบแบบจับเวลา มีภาษาไทยและอังกฤษให้เลือก
ไม่มี login ไม่มีฐานข้อมูล ไม่เก็บคะแนนหรือประวัติ บันทึกเฉพาะภาษาที่เลือกไว้ในเครื่อง เนื้อหาทั้งหมดเป็นไฟล์ใน repo นี้

## เริ่มใช้งานบนเครื่อง

```bash
npm install
npm run dev            # เปิด http://localhost:5173
npm run check:content  # ตรวจไฟล์เนื้อหาทั้งหมด
npm test               # ตรวจเนื้อหา + แบบฝึกหัด + ตัวแปลง Markdown
npm run build          # ตรวจเนื้อหาแล้ว build ลง dist/
```

ต้องใช้ Node 20 ขึ้นไป (แนะนำ 24)

## ขึ้น GitHub Pages

1. สร้าง repo บน GitHub แล้ว push โค้ดนี้ขึ้น branch `main`
2. ที่ repo ไปที่ **Settings → Pages → Build and deployment → Source** เลือก **GitHub Actions**
3. ทุกครั้งที่ push ขึ้น `main` workflow `.github/workflows/deploy.yml` จะตรวจเนื้อหา รันเทสต์ build แล้ว deploy
   เว็บจะอยู่ที่ `https://<username>.github.io/<repo>/`

Pull request จะถูกตรวจเหมือนกันแต่ไม่ deploy ไฟล์เนื้อหาที่ผิดรูปแบบจึงไม่มีทางขึ้นเว็บ

## โครงสร้าง

```

  tracks.json          4 เส้นทาง
  learning-paths.json  ลำดับเรียน พื้นฐาน ผลลัพธ์ และโปรเจกต์รวมสองภาษา
  exams.json           ชนิดบททดสอบ
  AUTHORING.md         กติกาการเขียนเนื้อหา

src/

  lib/markdown.js      แปลง Markdown เป็น topic
  lib/checks.js        ตรวจคำตอบแบบฝึกหัด
  lib/arise.js         ตรวจคำตอบและโครงสร้างของชุดฝึก Arise
  lib/vault.js         เข้ารหัส/ถอดรหัส (AES-GCM + PBKDF2) ใช้ได้ทั้ง Node และ browser
```

## เพิ่มหรือแก้เนื้อหา

- **แก้ไฟล์ตรง ๆ:** แก้ `content/topics/<id>.json` แล้วรัน `npm run check:content`
- **จากโน้ต Markdown:** เปิดหน้า “นำเข้า” ในเว็บ วางโน้ต กด “ลองเรียนเลย” เพื่อลองก่อน (ชั่วคราว หายเมื่อรีเฟรช)
  แล้วกด “ดาวน์โหลด .json” นำไปวางใน `content/topics/` (ไทย) หรือ `content/en/topics/` (อังกฤษ) เพิ่มไฟล์อีกภาษาที่มี `id` และโค้ดเดียวกัน จากนั้น commit และ push
- วางไฟล์ `.md` ใน `content/topics/` ได้โดยตรงเช่นกัน รูปแบบดูได้ในหน้า “นำเข้า”

ไฟล์ใน `content/topics/` และ `content/en/topics/` ต้องผ่านเกณฑ์เต็ม (strict) และมีหัวข้อกับฟิลด์สำหรับทำงานตรงกัน ต้องมีคำแปลอังกฤษครบทุกหัวข้อ ตัวตรวจจะรายงานข้อผิดพลาดหากไฟล์ภาษาใดขาดหาย ดูรายละเอียดใน `content/AUTHORING.md`
เช่น คำถามอย่างน้อย 8 ข้อและมีคำอธิบายทุกข้อ แบบฝึกหัดต้องมีเฉลยที่ผ่านทุกเกณฑ์ตรวจ

### รูปแบบ JSON ย่อ

```json
{
  "id": "sql", "code": "D1", "track": "data",
  "title": "Database / SQL", "blurb": "…",
  "mustKnow": [{ "tier": "must", "title": "…", "body": "…", "code": "…" }],
  "questions": [{ "prompt": "…", "options": ["…", "…", "…", "…"], "answer": 0, "explain": "…" }],
  "exercise": {
    "title": "…", "level": "กลาง", "tags": "…", "lang": "sql",
    "prompt": "…", "context": "…", "starter": "…", "solution": "…",
    "hints": ["…", "…"],
    "checks": [{ "label": "…", "pattern": "regex", "negate": false }]
  }
}
```

`tier` คือ `must` / `should` / `advanced` · `track` คือ `foundations` / `data` / `delivery` / `ai`
เกณฑ์ตรวจแบบฝึกหัดเป็น regex ที่เทียบกับคำตอบตัวพิมพ์เล็กที่ตัดคอมเมนต์ออกแล้ว
ถ้า `lang` เป็น `json` ใช้ `{ "label", "path", "op", "value" }` แทน (op: exists, equals, contains, containsAll, matches)

## แนวทางเรียนและการฝึก

หน้าแรกมีลำดับเรียนแนะนำ และทุกหัวข้อมีพื้นฐานที่ควรรู้ ผลลัพธ์ที่ควรทำได้ กับปุ่มไปอ่านสามเรื่องแรกโดยตรง ข้ามไปหัวข้อที่คุ้นเคยได้ เนื้อหาชั่วคราวที่นำเข้าไม่ใช้คำแนะนำของหัวข้อเดิม แม้ใช้ `id` เดียวกัน

โปรเจกต์รวมในหน้าแรกเชื่อม Git, SQL, Security, Testing และ CI/CD โดยให้ทำในเครื่องมือของผู้เรียน แล้วใช้เกณฑ์ review ตรวจหลักฐานจริง เว็บไม่ตรวจหรือให้คะแนนโปรเจกต์อัตโนมัติ

คำแนะนำเหล่านี้อยู่ใน `content/learning-paths.json` แยกจากโจทย์และคำแปล รัน `npm test` เพื่อตรวจความครบสองภาษา ลำดับ prerequisite และตำแหน่งเรื่องที่แนะนำให้อ่าน

หน้า “ลองตอบ” สุ่มครั้งละไม่เกิน 10 ข้อจากคลังของหัวข้อ ส่วนฝึกรวมและบททดสอบใช้จำนวนข้อที่ระบุไว้ แต่ละชุดหมุนผ่านคำถามที่ยังไม่เลือกในคลังนั้นก่อนเริ่มรอบใหม่ และไม่มีข้อซ้ำภายในชุด สถานะการสุ่มอยู่ใน memory ของหน้าเว็บเท่านั้น รีเฟรชแล้วเริ่มใหม่ การสลับภาษาไม่เปลี่ยนข้อหรือตัวเลือกของรอบที่กำลังทำ

## ชุดฝึก Arise (ต้องใช้รหัส)

เมนู “ชุดฝึก Arise” (`#/arise`) เป็นโจทย์ 168 ข้อจากชุดฝึกรุ่นก่อน มีทั้งข้อจากชีทอบรมและข้อแต่งเพิ่ม มีทั้งแบบเลือกข้อเดียว เลือกหลายข้อ และเรียงลำดับ ทุกตัวเลือกมีเหตุผล มีภาษาไทยและอังกฤษ แบ่งเป็น 3 แท็บ:

- **ฝึกทำโจทย์:** กรองตามหัวข้อ แหล่งที่มา และขอบเขตได้ ตรวจคำตอบแล้วเห็นเหตุผลของทุกตัวเลือก คอร์สที่เกี่ยวข้อง และแหล่งอ้างอิง
- **สรุปย่อ:** 14 บท แต่ละบทเปิดด้วยฉากสั้น ๆ แล้วจัดเป็นการ์ดหัวเรื่อง กฎ และกับดัก ปิดด้วยคำช่วยจำ มีโหมดทดสอบตัวเองที่ซ่อนคำอธิบาย มีเฉลยย่อรายข้อ และพิมพ์หรือบันทึก PDF ได้
- **บทเรียนและคอร์ส:** แนวทางอ่านรายบท รายชื่อคอร์สและชีท และแหล่งอ้างอิง

repo นี้เป็น public เนื้อหาชุดนี้จึงขึ้นไปเป็นไฟล์เข้ารหัสเท่านั้น และถอดรหัสใน browser เมื่อกรอกรหัสถูก รหัสไม่ได้อยู่ใน repo ขอจากเจ้าของ รีเฟรชหน้าแล้วต้องกรอกใหม่ เพราะไม่มีการเก็บอะไรไว้ใน browser

ถ้าจะแก้เนื้อหา ต้องมีต้นฉบับ `private/arise/th.json` และ `en.json` ในเครื่อง (ไม่อยู่ใน git) แก้แล้วรัน:

```bash
ARISE_PASSCODE='<รหัส>' node scripts/encrypt-arise.mjs   # ตรวจโครงสร้าง แล้วเขียน public/arise.enc.json
npm test
```

จากนั้น commit `public/arise.enc.json` ขึ้นไป

## สิ่งที่ตั้งใจไม่ทำ

ไม่มีบัญชีผู้ใช้ ไม่เก็บคะแนนหรือประวัติ (รีเฟรชแล้วเริ่มใหม่) ไม่รันโค้ดของผู้ใช้จริง แบบฝึกหัดตรวจจากรูปแบบคำตอบแล้วให้เทียบกับเฉลย ข้อยกเว้นเดียวคือชุดฝึก Arise ที่ต้องกรอกรหัส แต่ก็ยังไม่มีบัญชีผู้ใช้และไม่มี backend

ตัวเลือกภาษาเปลี่ยนข้อความและเนื้อหาทั้งเว็บระหว่างไทยกับอังกฤษ และจำภาษาที่เลือกไว้ใน browser เครื่องนั้นเท่านั้น เนื้อหาชั่วคราวที่นำเข้าจาก Markdown จะแสดงเป็นภาษาตามต้นฉบับที่นำเข้า ไม่แปลให้อัตโนมัติ
